# Open a JSON Lines file

Click any `.jsonl`, `.ndjson`, `.jsonlines` or `.jsonl.gz` file in the Explorer. It opens in JSONL Viewer as a table.

If the file opened as plain text, click the table icon at the top right of the editor, or right-click the file and pick Open in JSONL Viewer.

To get back to the text, click Open as Text in the viewer.
